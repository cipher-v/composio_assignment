Spot-check: was the agent right?
What this is: 20 apps picked at random (2 per category). For each one the agent made 4 claims. You check them against the vendor's docs, and the result becomes the accuracy score on the case-study page.
  1. Read the agent's answer. The links under it are the pages the agent cited, so open one if you're unsure.
  2. Click ✓ Right or ✗ Wrong. If it's wrong, choose the correct value from the dropdown.
  3. Optional: a short note on what was wrong. When you're done, click Export and save the file into the review folder.
What the answers mean
Access
self_serve_free: anyone can get API credentials for free · self_serve_trial: only during a free trial · paid_plan: API needs a paid plan · approval_required: vendor must approve you first (e.g. Google Ads developer token, Meta app review) · partner_or_sales: partnership or talk to sales · no_public_api
MCP
official: the vendor itself publishes an MCP server · community_only: only third-party servers · none_found
Verdict
ready_now: public docs + self-serve credentials · ready_with_friction: buildable, but with a paid plan, app review, trial, or it's a CLI to wrap · needs_outreach: needs a partner/sales deal · not_feasible: nothing callable
Primary auth
What an integration platform would use: oauth2 if the vendor offers OAuth apps; otherwise api_key, bearer_token, basic, and so on.
