Which of these 100 apps could become an agent toolkit today, and what's blocking the rest?

A research agent (Gemini on Vertex AI plus Google Search and a crawler) checked each app's auth, credential gating, API surface and MCP availability, citing the source for every claim. A second model then fact-checked every record, a crawler checked every cited URL, and a different model family (Claude) re-researched a random 20-app sample blind to measure accuracy.           Access
          self-serve free: anyone can sign up and get working API credentials for free (free tier, dev account, sandbox or open-source). self-serve trial: only during a time-limited trial. paid plan: API needs a paid subscription. approval required: free to start, but production needs app review, a developer-token approval or admin approval. partner / sales: partner program, enterprise contract or contact-sales. no public API.
          Verdict
          ready now: public docs plus self-serve creds, buildable this week. friction: buildable with a hurdle (paid plan, trial, app review, narrow API, or an open-source CLI that must be sandboxed). needs outreach: blocked on a partnership or sales deal. not feasible: nothing callable.
          MCP

          The agent: what it does, and where a human was needed

          A Python pipeline (run.py) runs each stage over all 100 apps in parallel and caches per-app JSON, so any stage can be re-run on its own. Models: Gemini 3 Flash does the research; Gemini 2.5 Pro, a different model, acts as the adversarial verifier. Both run on Vertex AI with Google Search grounding.

          agent · Flash + Search

          1. Discover

          Searches for the vendor's auth, pricing, API-reference and MCP pages.

          code

          2. Validate URLs

          An HTTP check on every candidate. Invented paths (404) are dropped before the agent reads anything.

          code + agent

          3. Read & research

          The crawler fetches the live pages; the agent writes notes where every claim has a URL and a verbatim quote.

          agent · schema

          4. Extract

          Notes become a strict JSON schema with fixed enums, so the rows can be clustered.

          code, then Pro + Search

          5. Verify

          The crawler re-fetches every cited URL (alive? official? is the quote really on the page?) and lints for contradictions. Then Pro re-derives every field, using those flags.

          independent model

          6. Spot-check

          A random sample of 20 apps (2 per category) is re-researched blind by a different model family (Claude) from the live docs. Every disagreement with Gemini is re-checked against the vendor page and decided with a cited quote.

              Run it

              Source repo: github.com/cipher-v/composio_assignment. Needs Python 3.12, a GCP project with Vertex AI enabled, and gcloud auth application-default login.

              uv venv && uv pip install -r requirements.txt
export COMPOSIO_RESEARCH_GCP_PROJECT=your-project
python run.py research --ids 4,31   # pass 1 on two apps (Attio, Google Ads)
python run.py all                   # full pipeline for all 100: research, crawl-check, verify, re-check, merge, analyze, page
python run.py review                # build the human spot-check sheet, then export human_labels.json
python run.py merge && python run.py score && python run.py analyze && python run.py page
